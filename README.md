# AgentFlow W8 Golden Project template

This is a tiny, dependency-free TodoList project used to initialize the empty
`GeHahahaha/demoTest` repository. It is intentionally small enough for a real
model/FreshSpawn/Skill/SCM-MCP run while still having source code and unit and
integration tests.

Commands:

```text
npm test
npm run test:unit
npm run test:integration
```

The template itself is not a remote baseline and contains no credentials. W8
must copy these files into the remote repository, create `main`, record the
resulting commit SHA, and then update the environment manifest with that SHA.
